# NOIR DISTRICT - Курсовой проект (WEB)

## О проекте

`NOIR DISTRICT` - это фронтенд-прототип интернет-магазина одежды, выполненный как курсовой проект.
Проект реализован без бэкенда, на чистых `HTML`, `CSS`, `JavaScript`, с упором на:

- современный интерфейс онлайн-магазина;
- каталог товаров с фильтрацией и сортировкой;
- корзину с расчётом стоимости, доставки и скидок;
- систему рекомендаций "с чем сочетать".

## Технологии

- `HTML5`
- `CSS3` (адаптивная верстка, grid/flex)
- `JavaScript (ES6+)`
- `jQuery 3.7.1` (работа с событиями и DOM)
- `Chart.js 4.x` (график распределения каталога)
- Локальное хранение данных через `localStorage`
- Простая CMS товаров без backend (`pages/admin.html`)

## Что реализовано

### 1) Каталог товаров

- карточки товаров с изображением, названием, категорией, рейтингом, ценой;
- единый визуальный формат изображений (с индивидуальной подгонкой масштаба);
- быстрые фильтры:
  - поиск по названию;
  - выбор категории;
  - выбор стиля;
  - сортировка (популярность, цена, название).
- автодополнение поиска на `jQuery UI`.

### 1.1) CMS без backend

- отдельная страница `pages/admin.html`;
- добавление, редактирование и удаление товаров;
- сохранение каталога в `localStorage` (`noir-products-v1`);
- кнопка сброса к базовому каталогу.

### 2) Корзина

- добавление товара в корзину из каталога и из рекомендаций;
- изменение количества товара (`+ / -`);
- расчёт:
  - количества товаров;
  - подытога;
  - доставки;
  - скидки;
  - итоговой суммы.

### 3) Логика доставки

- бесплатная доставка от `7000 ₽`;
- если сумма меньше порога, добавляется стоимость доставки;
- отображается прогресс-бар до бесплатной доставки;
- динамическая подсказка, сколько осталось добрать.

### 4) Промокоды

Поддерживаются промокоды:

- `NOIR10` - скидка 10%
- `STUDENT15` - скидка 15%

Скидка учитывается в итоговой сумме заказа.

### 5) Подбор сочетающихся товаров

Кнопка "Сочетается с" запускает улучшенный алгоритм рекомендаций:

- учитываются совпадения стилей;
- учитывается совместимость категорий;
- учитывается близость ценового сегмента;
- учитывается рейтинг товара;
- в подборке поддерживается разнообразие категорий для сборки цельного лука.

### 6) Дополнительный контент

- промо-блок коллекции;
- информационные секции: преимущества, доставка/оплата, FAQ;
- адаптивный layout для десктопа, планшета и мобильных устройств.
- отдельные страницы `about.html`, `delivery.html`, `faq.html` с общей верхней навигацией (навигационная модель сайта).
- аналитика каталога на `Chart.js` (столбчатая и круговая диаграммы).
- анимированные метрики на `CountUp.js`.

### 7) Сохранение состояния

- корзина и примененный промокод сохраняются в `localStorage`;
- после перезагрузки страницы состояние восстанавливается.

### 8) Быстрая ручная настройка товаров

Для изменения ассортимента откройте `js/data.js` и отредактируйте массив `window.NOIR_BASE_PRODUCTS`.
Основные поля:

- `name` - название товара;
- `price` - цена;
- `styles` - стили, к которым относится товар;
- `imageScale` и `imageOffsetY` - визуальная подгонка иконки в карточке.

## Структура проекта

```text
.
├─ pages/          # HTML-страницы сайта (index/about/delivery/faq/admin)
├─ css/            # стили: screen.css + responsive.css
├─ style.css       # точка входа (@import css/screen.css и css/responsive.css)
├─ js/
│  ├─ data.js      # каталог и справочники (массив объектов)
│  └─ app.js       # логика каталога, корзины, рекомендаций, графиков
├─ admin.js        # CMS: форма и таблица товаров
├─ images/         # изображения товаров
├─ docs/           # документы .docx
├─ robots.txt      # правила индексации
├─ sitemap.xml     # карта сайта (демо)
└─ README.md
```

## Как запустить

1. Скачать или клонировать проект.
2. Открыть папку проекта.
3. Запустить `pages/index.html` в браузере.

Дополнительная сборка или сервер не требуются.

## Соответствие методичке (кратко)

В проекте реализованы ключевые требования методических указаний:

- HTML5, CSS3, JavaScript;
- адаптивность и интерактивность интерфейса;
- навигационные панели и фильтры;
- работа с графикой и карточками товаров;
- JS-сценарии для корзины, рекомендаций, доставки, промокодов;
- базовые элементы продвижения: `meta`-теги, `robots.txt`, `sitemap.xml`.

Для полной подготовки к защите рекомендуется:

- приложить результаты валидации W3C HTML/CSS;
- зафиксировать кроссбраузерное тестирование;
- добавить в пояснительную записку схему модели сайта и скриншоты экранов.

## Пользовательский сценарий

1. Пользователь открывает каталог и выбирает фильтры.
2. Добавляет товары в корзину.
3. При необходимости применяет промокод.
4. Видит стоимость с учетом доставки и скидки.
5. Нажимает "Сочетается с" для получения рекомендаций по образу.
6. Оформляет заказ.
